# 🎮 统一游戏状态与存档设计

LingChat 将对话、角色、舞台和剧本状态统一在当前游戏状态中。这个设计使自由聊天与剧本演出可以共享同一存档，而不需要在两套记忆系统之间迁移。

## 核心概念

- **GameStatus**：当前存档的角色、舞台、台词树、背景、音乐和剧本状态。
- **RoleManager**：管理当前角色、在场角色和每个角色的记忆构建。
- **Line**：对话历史的原子记录，支持回溯与分支。
- **ScriptStatus**：剧本章节、变量与执行进度。
- **MemoryBank**：与角色和存档关联的长期记忆。

## 设计结果

- 存档可恢复角色、对话、舞台和剧本进度。
- 剧本可让当前主角色与 NPC、旁白共同参与。
- 每位角色从共享台词树重建自己的 LLM 上下文。
- 剧本事件和自由对话使用同一套状态与持久化模型。
