# 🛠️ AI 工具调用 (Function Calling)

LingChat 将用户对话、主动对话和部分剧本 AI 对话接入统一的工具循环。模型请求工具后，运行时执行工具、把结果回填上下文，并继续生成最终回复。

## 调用闭环

```text
生成请求 -> 权限计算 -> 下发工具定义 -> 模型请求工具
-> 执行工具 -> 工具结果写入台词树 -> MemoryBuilder 还原历史 -> 下一轮生成
```

工具由 Rust `ToolRegistry` 注册并由执行器统一校验、解析和超时控制。调用过程会落入 `line` 表，以便角色在后续回合保有相关上下文。

## 权限模型

权限不是单一开关，而是“**场景组 x 角色组**”的交集：调用来源映射到场景组，角色必须属于启用的角色组，最终可用工具集由两边共同裁剪。

配置文件位于 `<data_dir>/tool_permissions.toml`。默认配置倾向于最小权限，新角色默认不拥有工具权限。

::: warning
权限配置当前没有完整的图形管理页。修改 TOML 或扩展工具前，必须理解调用来源、角色组和 `all_tools` 的实际含义。
:::

扩展新工具时，实现 `Tool` trait、注册工具、配置权限并添加测试。上游详细实现文档位于 `docs/function_call/`。
