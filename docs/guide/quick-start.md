# 🚀 快速上手指引

欢迎来到 **LingChat**（灵动聊天陪伴助手）！LingChat 是一款高自由度的沉浸式 AI-Galgame 伴侣系统，不仅拥有能够感知情绪的立绘微表情、低延迟 VITS 语音，还具备独立的树状永久记忆、桌面宠物与剧本剧情系统。

本指南将带你在 **3 分钟内** 完成从下载、配置到开启第一次对话的全流程。

---

## 📋 准备工作

在开始之前，你只需要准备一个 **大模型 API 密钥 (API Key)**。

::: tip 推荐的大模型提供商
- **[DeepSeek (深度求索)](https://platform.deepseek.com/)**：强烈推荐，性价比极高，角色扮演与逻辑推理表现极佳。
- **[阿里云百炼 / 通义千问](https://bailian.console.aliyun.com/)**：新用户赠送海量额度，且同时支持文本模型与视觉模型（用于桌面感知）。
- **[Moonshot / Kimi](https://platform.moonshot.cn/)**：支持超长上下文与快速响应。
- **本地 Ollama / OpenWebUI**：适合拥有独立显卡并希望完全离线运行的用户。
:::

## ⚡ 快速三步起飞

### 第一步：获取与解压 LingChat

1. 前往 GitHub [Releases 发行版页面](https://github.com/SlimeBoyOwO/LingChat/releases) 下载最新版本的客户端：
   - 💻 **Windows 10/11 64位**：下载 `LingChat-vX.X.X-windows.7z` 或安装程序 `Setup.exe`。
   - 📱 **Android 手机**：下载 `LingChat-vX.X.X.apk`。
   - 🐧 **Linux / macOS**：下载对应的跨平台压缩包。
2. 解压下载的 `.7z` 压缩包到**不含中文字符**的英文路径（例如 `D:\LingChat\`）。

::: warning 注意事项：Windows Defender 误报防护
如果解压后发现主程序不见了，通常是由于被 Windows Defender 等安全软件误拦截。请进入 **Windows 安全中心 ➔ 病毒和威胁防护 ➔ 保护历史记录**，将 `LingChat` 目录添加为排除项并允许运行。
:::

---

### 第二步：首次启动与大模型配置

<FancyCard type="feature" title="开箱即用的配置面板" icon="⚙️">
新版本已提供可视化的一键配置界面，你无需手动修改复杂的配置文件。
</FancyCard>

1. 双击运行 `LingChat.exe`（或手机端打开 LingChat App）。
2. 在初始主界面点击 **开始游戏**。
3. 打开右上角的 **菜单栏 ➔ 高级设置 ➔ 大模型提供商**。
4. 点击 **添加提供商**，填写以下核心信息：
   - **提供商名称**：如 `DeepSeek` / `Qwen`
   - **Base URL**：如 `https://api.deepseek.com`
   - **API Key**：填写你申请到的 `sk-xxxxxx`
   - **模型名称**：如 `deepseek-chat` 或 `qwen-plus`
5. 滑动到底部点击 **保存配置** 并重启软件。

---

### 第三步：开启你的第一段对话

1. 返回主界面，选择你喜爱的角色（系统默认内置了 **诺一钦灵** 与 **风雪**）。
2. 点击 **进入对话**，在底部的输入框中敲下第一句问候：
   > *“你好呀钦灵，初次见面，请多关照喵！”*
3. 伴随着专属打字音效与语音，立绘表情会根据对话情感实时联动（高兴、害羞、疑惑等 19 种细粒度情绪），开始属于你们的故事！

## ❓ 常见问题排查

::: details 1. 点击发送后 AI 一直显示“正在思考中”，没有回复怎么办？
- **检查网络**：确认是否能正常访问对应大模型平台的 API 地址。
- **检查余额**：确认你的大模型账户是否有可用额度。
- **查看报错**：打开右上角菜单 ➔ **日志面板**，查看详细的 HTTP 错误码（如 401 表示 Key 错误，429 表示并发超限或欠费）。
:::

::: details 2. 网页端游玩与客户端游玩有什么区别？
在 Python 架构版本中，程序启动后在本地监听了 `8756` 端口。你可以在现代浏览器（Chrome / Edge）直接访问 `http://localhost:8756` 进行游玩，界面和功能与客户端完全一致，且支持更方便的 F5 刷新与开发者调试。而在 Tauri 架构版本中，推荐直接使用客户端窗口。
:::

::: details 3. 为什么 AI 角色会突然说日语？
LingChat 内置了多语言翻译与语音生成流水线。如果你开启了日语 VITS 语音，系统会自动在后台将对话转换为日文音标驱动语音合成。新版本已大幅优化了提示词解析，杜绝了翻译泄露问题；若偶发异常，可前往高级设置检查语音语言配置。
:::
