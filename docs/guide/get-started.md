# 下载与安装
欢迎体验LingChat~

本页介绍如何在不同操作系统上下载并安装 LingChat。

## 0 - 网络连接
::: info
请你确保你能够正常访问Github，以得到最新的LingChat安装包
:::
## 1 - 下载
1. 前往[LingChat Releases](https://github.com/SlimeBoyOwO/LingChat/releases)
2. 找到标有`Latest`的最新版
![下载界面](/guide-shot/releases-latest.png)
3. 下滑页面，找到`Assets`
![Assets](/guide-shot/assets.png)
Windows平台，请找到`.exe`后缀的安装包，Android平台请下载`.apk`后缀的安装包
::: tip
考虑到国内访问GitHub网络状况不佳，下载速度很可能极慢，可以到LingChat用户群自行下载~
:::

## 2 - 安装

1. 双击下载好的安装包
2. 按照安装向导提示完成安装。

启动后若出现主界面，即表示安装成功。


## 下一步

安装完成后，请继续阅读[快速开始指引](./quick-start.md)。
