# 下载与安装

欢迎体验 LingChat~

本页介绍如何在不同操作系统上下载并安装 LingChat。

## 网络连接

::: info
请你确保你能够正常访问 GitHub，以得到最新的 LingChat 安装包。
:::

## 下载

1. 前往 [LingChat Releases](https://github.com/SlimeBoyOwO/LingChat/releases)
2. 找到标有 `Latest` 的最新版
   ![下载界面](/guide-shot/releases-latest.png)
3. 下滑页面，找到 `Assets`
   ![Assets](/guide-shot/assets.png)

Windows 平台请下载 `.exe` 后缀的安装包，Android 平台请下载 `.apk` 后缀的安装包。

::: tip
考虑到国内访问 GitHub 网络状况不佳，下载速度很可能极慢，也可以到 LingChat 用户群自行下载~
:::

## 安装

1. 双击下载好的安装包
2. 按照安装向导提示完成安装

启动后若出现主界面，即表示安装成功。

## 下一步

安装完成后，请继续阅读[第一次游玩](./quick-start)。
