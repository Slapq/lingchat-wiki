## 🔄 程序更新与资源同步

桌面端更新分为两层：程序本体由 Tauri 更新机制检查发行版并校验签名；默认资源通过 `data_manifest.json` 比对后按需同步。资源清单只描述官方文件，用户创建的角色、剧本、截图、语音缓存和 SQLite 数据不会被更新流程覆盖或删除。

资源同步使用 SHA-256 清单进行完整快照比对，新增和变更文件采用临时文件后原子替换；不再属于官方资源的文件会移入 `.trash/`，而不是直接删除。

::: tip
更新提示会在应用内显示。若更新失败，请检查网络、磁盘空间和 GitHub Releases 可达性，再参阅 [社区支持与故障排查](/guide/troubleshooting)。
:::
