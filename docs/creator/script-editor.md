# ✍️ 可视化剧本编辑器

当前 LingChat 提供应用内剧本编辑器。它以 Schema 驱动表单编辑事件，负责素材、角色和章节管理，并在不污染日常对话的前提下提供试玩。

## 创作流程

1. 打开剧本编辑器，新建独立剧本或角色羁绊剧本。
2. 创建章节、事件与素材引用。
3. 使用章节流程和属性面板调整演出与分支。
4. 运行校验器，处理 `error`、`warn` 和 `info` 诊断。
5. 在编辑器内试玩，确认剧情和资源后保存发布。

## 关键保障

- 前端只处理 JSON，YAML 语义与写盘由 Rust 层统一管理。
- 文件写入使用原子写并保留 `.bak` 备份。
- 所有剧本路径都经过校验，避免目录穿越。
- 试玩使用真实引擎，并通过会话快照、生成代号和前端状态快照隔离，退出后恢复日常对话。

## 编辑器能力

- 编辑器目前覆盖 17 种事件，包含场景、对话、变量、分支与 `unlock_achievement` 成就事件。
- 章节编辑支持撤销、自动保存、事件折叠、流程图和素材管理。
- 校验器会按事件、章节图和变量给出稳定的 `error`、`warn` 与 `info` 诊断；成就 ID 会额外检查与内置成就或同剧本定义的冲突。
- 编辑器可以使用专属 Skill Agent 助手读取已安装的技能包，协助创建章节、检查内容和处理需要确认的操作。

## 试玩隔离

试玩复用真实剧本引擎，但不会成为普通对话的一部分。后端会快照共享游戏状态，前端会快照舞台和事件队列；退出或离开编辑器时按顺序恢复。生成代号同时保护普通台词与工具结果，避免中止试玩后的迟到结果写回当前存档。

::: tip
文本编辑仍适合高级作者，但新剧本优先使用可视化编辑器创建，能获得结构校验、自动保存和试玩支持。
:::
