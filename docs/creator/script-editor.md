# ✍️ 可视化剧本编辑器

当前 LingChat 提供应用内剧本编辑器。它以 Schema 驱动表单编辑事件，负责素材、角色和章节管理，并在不污染日常对话的前提下提供试玩。

## 创作流程

1. 打开剧本编辑器，新建独立剧本或角色羁绊剧本。
2. 创建章节、事件与素材引用。
3. 使用章节流程和属性面板调整演出与分支。
4. 运行校验器，处理 `error`、`warn` 和 `info` 诊断。
5. 在编辑器内试玩，确认剧情和资源后保存发布。

## 关键保障

- 前端只处理 JSON，YAML 语义与写盘由 Rust 层统一管理。
- 文件写入使用原子写并保留 `.bak` 备份。
- 所有剧本路径都经过校验，避免目录穿越。
- 试玩使用真实引擎，并通过会话快照、生成代号和前端状态快照隔离，退出后恢复日常对话。

::: tip
文本编辑仍适合高级作者，但新剧本优先使用可视化编辑器创建，能获得结构校验、自动保存和试玩支持。
:::
