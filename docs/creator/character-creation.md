# 🎨 角色卡制作与触摸配置

角色资源位于 `data/game_data/characters/<角色名>/`。建议先复制一个官方角色目录，再替换素材与 `settings.yml`，以确保字段与当前版本一致。

## 目录结构

```text
characters/<角色名>/
├── avatar/                   # 情绪立绘（目录名固定为单数 avatar）
│   ├── 正常.webp
│   ├── 高兴.webp
│   ├── ...
│   ├── 头像.webp             # 菜单/角色卡头像，不是情绪
│   └── 泳装/                 # 服装子目录，目录名即服装显示名
│       ├── 正常.webp
│       └── ...
└── settings.yml              # 人设、显示、触摸、服装与语音配置
```

角色标识取自**目录名**。`settings.yml` 中并没有 `character_folder` 之类的字段；改名时目录和配置一起改即可，改完通过应用内角色管理刷新或重开角色列表确认。

## 准备素材

### 情绪立绘

静态角色支持以下 20 个情绪文件名（以官方角色目录为准）：

```text
正常  高兴  兴奋  平静  害羞  羞耻  心动  惊讶  疑惑  紧张
慌张  担心  害怕  生气  厌恶  伤心  无奈  调皮  自信  认真
```

- `平静` 缺失时会回退显示 `正常`，其余情绪缺失则该状态无立绘。
- 应用内上传支持 PNG / JPEG / WebP，单张不超过 20 MB，边长不超过 8192 像素，上传后会统一转成 PNG 并清理同情绪的其他格式。
- 运行时查找还认 `bmp`、`gif`，手写文件放进去也能读到，但建议统一用 WebP。
- 立绘需透明背景，且**同一套服装的各情绪立绘共用同一张画布**（同宽高比即可，不必同尺寸），否则触摸区域会错位。

### 服装

- 服装是 `avatar/` 下的子目录，**目录名就是服装显示名**。
- 根目录那一套固定叫「默认」；配置里写 `default`、`默认` 或留空，都归到它。
- 新增服装需要在 `settings.yml` 的 `clothes` 里补一条，否则只有目录没有提示词。

## settings.yml 字段速查

| 字段 | 类型 | 默认值 | 说明 |
|---|---|---|---|
| `ai_name` | string | `ai_name未设定` | 角色名，**必填** |
| `ai_subtitle` | string | 空 | 角色名后的副标题 |
| `user_name` | string | `user_name未设定` | 对玩家的称呼，**必填** |
| `user_subtitle` | string | 空 | 玩家副标题 |
| `title` | string | 空 | 角色卡标题 |
| `info` | 多行 string | 空 | 角色简介 |
| `system_prompt` | 多行 string | 空 | 人设主提示词，角色卡的核心 |
| `system_prompt_example` | 多行 string | 空 | 台词示例，用于对齐语气 |
| `system_prompt_example_old` | 多行 string | 空 | 旧格式示例（含中日对照），兼容保留 |
| `thinking_message` | string | `正在思考中...` | 思考中气泡的文案 |
| `scale` | float | `1.0` | 主对话立绘缩放 |
| `offset_x` / `offset_y` | float | `0` | 主对话立绘像素偏移 |
| `bubble_top` | int | `5` | 对话框垂直位置，百分比 |
| `bubble_left` | int | `20` | 对话框水平位置，百分比 |
| `avatar_mode` | string | `live2d` | 主对话形象：`live2d` 或 `image` |
| `clothes` | list | 空 | 服装列表，每项含 `name` 与 `prompt` |
| `clothes_name` | string | 空 | 当前穿着，留空即默认服装 |
| `scale_p` | float | `1.0` | 桌宠立绘缩放 |
| `offset_x_p` / `offset_y_p` | float | `0` | 桌宠立绘偏移 |
| `avatar_mode_p` | string | 同 `avatar_mode` | 桌宠形象 |
| `pet_frameless` | bool | `false` | 桌宠无框模式（隐藏圆框与粒子） |
| `tts_type` | string | 空 | 语音引擎，如 `localsbv2api` |
| `voice_lang` | string | 空 | 语音语种，如 `ja`、`zh` |
| `voice_dialect` | string | 空 | 仅 cosyvoice + `zh` 生效，如「四川话」 |
| `voice_models` | map | 空 | 各引擎的音色参数，由应用内语音设置写入 |
| `body_part` | map | 空 | 触摸区域，见下文 |
| `live2d` | map | 空 | 模型与情绪绑定，详见 Live2D 文档 |

::: warning 
`avatar_mode` 写成 `live2d` 以外的非法值时，会按 `live2d` 处理（这是为了老配置兼容）。想要强制静态立绘，必须写 `image`。
:::

## 触摸区域（body_part）

`body_part` 描述「摸到立绘的哪一块要发什么话」。触摸模式下应用会把不可见多边形铺在立绘上，点中即把提示词作为玩家消息发给 AI。Live2D 角色不走这条路径，可摸范围由模型侧决定。

### 数据形状

```yaml
body_part:
  默认:                        # 顶层键 = 服装显示名
    头:
      message: 你摸了一下{角色名}的头
      polygons:
        - [[0.41, 0.17], [0.49, 0.14], [0.47, 0.30]]
        - [[0.52, 0.18], [0.58, 0.16], [0.56, 0.29]]   # 同一部位可挂多块
  泳装:
    头: { message: "...", polygons: [[[0.40, 0.20], [0.50, 0.20], [0.45, 0.30]]] }
```

- 顶层键是服装显示名，与 `avatar/` 下的子目录名一致；根目录那套写「默认」。
- 每个部位一句 `message`，同一部位的多块多边形共用这一句。
- `message` 留空时回落到「`{user_name}`戳了一下你」。

### 坐标怎么算

`polygons` 里的点是**相对立绘图片自身**的 0..1 归一化坐标，**原点在左上角**。

```text
x = 点在图片中的横向像素 / 图片宽度
y = 点在图片中的纵向像素 / 图片高度
```

它与窗口尺寸、`scale`、`offset_x/offset_y`、应用级缩放**全都无关**，所以换分辨率、调缩放、多角色同台时区域都会跟着立绘走。

成立的前提仍是同一套服装的各情绪立绘共用同一张画布。如果某套立绘按情绪单独裁切过，区域必然偏移，此时应改用同一张底图。

### 用编辑器画

入口：角色设置 → 触摸区域 → 编辑触摸区域（全屏编辑器）。

| 操作 | 行为 |
|---|---|
| 侧栏「新增区域」 | 建好空区域并聚焦名字，命名后再到画布上画 |
| 空白处单击 | 有选中区域就往它上面加一块，否则等同新增 |
| 双击 / 回车 / 点回第一个顶点 | 闭合多边形（顶点不足三个则丢弃） |
| 拖动顶点 | 移动顶点，使框选区域在图片范围内 |
| 选中顶点后 Delete | 删除该顶点；只剩三个时删除整块 |
| Esc | 放弃正在画的；无则清除选中 |
| 侧栏「＋多边形」 | 给该区域追加一块 |

只命名不画多边形，保存时会被丢掉——没有多边形就永远摸不到。



## 分享与迁移

可在应用内把角色导出为 `.zip` 或 `.7z`，再在桌面端或 Android 导入。归档会进行路径安全、条目数和压缩比检查。详见 [角色导入导出与归档](/manual/role-archive)。

旧版 `settings.txt v3.0.1` 迁移说明已不适用于当前 `settings.yml` 格式。
