# 🐱 LingPal 桌面宠物模式

LingPal 是 LingChat 的**应用内窗口模式**，不是需要单独启动或连接主程序的第二个可执行文件。切换后，应用会调整窗口尺寸、装饰、置顶与鼠标命中行为，形成适合悬浮陪伴的桌宠界面。

## 使用方式

1. 在 LingChat 中完成角色和模型配置。
2. 在应用菜单中切换到桌宠模式。
3. 根据需要开启主动对话、日程提醒或屏幕感知。

桌宠模式与普通窗口使用同一应用状态，因此当前角色、对话、存档、记忆和设置会连续保留，无需同步或刷新网页。

::: warning 隐私说明
屏幕感知和主动对话均应由用户主动启用。启用视觉能力前，请确认已配置视觉模型，并了解它可能读取的屏幕内容。
:::

::: info 技术说明
当前实现通过 Tauri 的 `set_pet_mode` 命令在同一进程内切换窗口状态；不会依赖旧版 Python 后端或网页端。
:::
