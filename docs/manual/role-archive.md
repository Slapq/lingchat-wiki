# 📦 角色导入导出与归档

LingChat 支持把完整角色目录导入或导出为 `.zip` 与 `.7z`，用于桌面端和 Android 端之间迁移角色资源。

## 使用方式

- 在角色设置中选择“从压缩包导入”，选择 `.zip` 或 `.7z` 文件。
- 在角色卡片菜单中选择导出格式，再选择保存位置。
- Android 使用系统文件选择器和保存位置；桌面端使用本地文件路径。

导入完成后，应用会重新扫描角色目录并更新角色列表。归档中必须包含角色的 `settings.yml`。

## 冲突与取消

导入时可按应用提示跳过、重命名或覆盖同名角色。大型归档会显示进度，导入过程中可取消；取消会停止后续写入，但不会自动撤销已经写入的文件。

## 安全限制

为保护数据，应用会拒绝路径穿越、加密压缩包、超出条目上限的归档和异常压缩比文件。请先在外部解密受密码保护的压缩包。

::: tip
归档是迁移角色资产的推荐方式。直接复制目录时，也应确保最终结构位于 `data/game_data/characters/<角色名>/`。
:::
