# 👀 主动对话与屏幕感知

主动系统在用户启用相关功能后，结合日程、待办、重要日子、活动状态与屏幕变化，为角色提供适合当前情境的对话线索。

## 可参与的信号

- **日程与待办**：在合适时间提供提醒或话题。
- **重要日子**：可用于当天首次互动或指定日期提醒。
- **活动状态**：系统会将活动归类为工作、游戏、浏览或空闲等情境，避免在不合适的时机打扰。
- **屏幕感知**：在用户授权并配置视觉模型后，可通过截图和视觉模型提供额外上下文。

## 使用建议

1. 先在日程页面维护需要提醒的事项。
2. 在设置中按需启用主动对话和屏幕感知。
3. 为视觉感知分配支持图片输入的模型。
4. 通过“看桌面”等对话确认视觉能力是否可用。

::: warning 隐私与打扰控制
屏幕感知不是默认必须功能。请只在接受截图内容被用于当前 AI 上下文时启用；工作场景下建议降低主动提醒频率。
:::

## 当前实现

当前系统由 Rust 的 `proactive_system` 管理，使用原生截图与活动监测能力；旧博客中的 `mss`、`easyocr`、`pynput` Python PoC 只是历史设计记录，不是当前安装或配置步骤。
