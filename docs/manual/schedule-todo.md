# 🍅 日程、待办与番茄钟

LingChat 在应用内提供日程、待办、重要日子与番茄钟等效率工具。它们既可由用户直接管理，也可在授权的工具调用场景中被角色用于提醒与陪伴。

## 日程与待办

- **日程**：创建分组和具体提醒，在指定时间触发。
- **待办**：按分组管理任务，可标记完成、设置优先级和截止时间。
- **重要日子**：在日历中维护一次性或周期性日期。
- **番茄钟**：用于专注节奏与休息提醒。

在应用内打开日程页面即可新增、编辑或删除内容。保存后的信息会由当前运行时数据管理，不需要手动维护旧版的 `year.json` 或前端示例代码。

## 与 AI 陪伴的关系

主动系统可以把未完成待办、到期日程和重要日子作为对话线索。是否发起提醒仍取决于用户设置、角色状态与活动情境。

::: tip
工具调用的权限由场景和角色共同决定。开发者如需扩展日程工具，请参阅 [AI 工具调用](/design/function-call)。
:::
