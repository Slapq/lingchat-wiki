# 💾 记忆与对话存档

LingChat 将对话历史、角色状态和记忆持久化到 SQLite。每个存档拥有自己的对话台词树与角色相关上下文，加载存档时可恢复对话、舞台和运行中的剧情状态。

## 数据如何组织

- `save` 保存当前会话的入口与元数据。
- `line` 是对话历史的原子记录，以父子关系构成可回溯的台词树。
- `role` 描述角色资源与身份。
- `memory_bank` 保存与角色、存档关联的长期记忆。
- `running_script` 保存进行中的剧本进度与变量。

每条台词可以带有情绪、语音内容、动作、发言角色、思考过程和工具调用信息。MemoryBuilder 会按当前角色重建 LLM 所需的上下文：角色自己的发言保持为助手消息，其他角色、旁白与场景信息作为背景上下文参与构建。

## 对话回溯

台词树允许从历史节点继续对话或生成新分支。不要直接编辑数据库文件；请通过应用内的存档和历史功能操作。

::: info
当前后端使用 Rust 与 SeaORM，而不是旧版文档中的 Python SQLModel/SQLAlchemy。详细算法请阅读 [LLM 记忆构建器](/design/memory-builder)。
:::
