# 📖 功能全景导览

LingChat 是运行在 Tauri 原生应用中的 AI-Galgame 陪伴系统。每个存档保存独立对话状态与记忆，角色、场景、剧本和工具能力围绕同一套游戏状态协作。

## 核心体验

| 功能 | 说明 |
| --- | --- |
| 永久记忆与存档 | 对话台词树、角色记忆和舞台状态随存档持久化。 |
| 情绪与立绘 | 模型回复可驱动情绪分类、表情、动作与气泡表现。 |
| 语音 | 支持内置 Style-Bert-VITS2 和多个外置 TTS 适配器。 |
| 主动陪伴 | 日程、待办、重要日子、屏幕感知与活动状态可参与提醒。 |
| 剧本与羁绊 | 多角色剧情、分支、事件和成就可与日常角色联动。 |
| 扩展能力 | 支持 Function Calling、Skills 与受限 Python 插件。 |
