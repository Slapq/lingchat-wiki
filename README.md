# LingChat 文档

这是 **LingChat 官方文档站**，使用 VitePress 构建。

文档内容从钦灵的个人博客 [LingBlog](https://github.com/SlimeBoyOwO/LingBlog) 中迁移而来，并独立整理为 `lingchat-wiki` 仓库。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

项目主页：[SlimeBoyOwO/LingChat](https://github.com/SlimeBoyOwO/LingChat)
